DB 직접 접근 없음

앱은 데이터베이스에 직접 붙지 않습니다. 모든 조회와 저장은 인증된 서버 API를 통해서만 이뤄집니다.

설치 방법

처음 한 번만 확인하면 됩니다.

1. Windows에 설치

  1. Windows용 설치하기를 눌러 install.exe.zip을 받고 압축을 풉니다.
  2. install.exe를 실행합니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다.
  3. 설치가 끝나면 바탕 화면이나 시작 메뉴의 BH Security Code를 실행합니다.

2. Android에 설치

  1. 휴대폰 브라우저에서 이 페이지를 열고 Android 앱 받기를 누릅니다.
  2. 내려받은 BH_SecurityCode.apk를 엽니다. "출처를 알 수 없는 앱" 안내가 뜨면 해당 브라우저(또는 내 파일)에 설치 허용을 켭니다.
  3. 이미 설치돼 있다면 같은 방법으로 덮어 설치합니다. 저장된 설정은 그대로 유지됩니다.

3. 서버 주소와 로그인

처음 실행하면 로그인 화면이 열립니다. PC는 오른쪽 아래 ⚙, Android는 로그인 화면의 서버 설정에서 관리자에게 받은 서버 주소를 넣은 뒤 계정으로 로그인하세요. 다른 기기에서 이미 로그인 중이면 확인을 거쳐 이 기기로 세션을 옮깁니다.
